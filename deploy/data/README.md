# 데이터 인프라

PostgreSQL, Redis, Kafka의 배포 설정을 관리한다.

## 역할
- PostgreSQL: 좌석, 예약, 티켓의 영구 데이터 및 정합성 기준
- Redis: 캐시와 대기열 등 빠른 임시 상태 처리
- Kafka: 예약 확정 등 비동기 이벤트 전달

## 관리 대상
- 구성 요소별 Helm values 및 버전
- PVC, 저장 용량, 데이터 보존 설정
- CPU·메모리 설정
- 인증 정보 참조
- 메트릭 수집 설정

## 운영 원칙
- 데이터 삭제를 수반하는 작업은 영향을 확인한다.
- 백업 생성과 실제 복원 검증을 구분한다.
- Redis만으로 좌석 중복 판매 방지를 보장하지 않는다.
- 애플리케이션 테이블 migration은 해당 서비스와 함께 관리한다.

백업·복구 절차와 장애 대응 기록은 docs/에 작성한다.
