# 프로젝트 문서

설계 결정과 실제 구축·운영 과정을 기록한다.

## 기록할 내용
- 아키텍처와 기술 선택 이유
- 설치 명령과 설정 파일 위치
- 배포 및 버전 변경 절차
- SLI·SLO 정의와 측정 결과
- 부하 테스트 조건 및 결과
- 장애 진단·복구 절차
- 장애 실험과 사후 분석
- 백업 및 복원 검증

## 작성 원칙
- 명령 실행 위치를 개발 PC / 서버 Windows / 서버 WSL로 구분한다.
- 계획, 실행 완료, 검증 완료를 구분한다.
- 사용 버전과 기대 결과를 함께 적는다.
- 실패 원인을 추측과 확인된 사실로 구분한다.
- 비밀번호와 인증 정보는 기록하지 않는다.

문서는 해당 작업을 진행할 때 추가한다.
