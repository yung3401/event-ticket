# gRPC API 계약

서비스 간 통신에 사용하는 Protocol Buffers 정의를 관리한다.

## 관리 대상
- .proto 파일
- 서비스 및 RPC 정의
- 요청·응답 메시지
- 코드 생성 및 계약 검증 설정

## 작성 원칙
- 서비스와 API 버전별로 파일을 구분한다.
- 필드 번호를 임의로 바꾸거나 재사용하지 않는다.
- 삭제한 필드 번호와 이름은 reserved로 남긴다.
- 호환성을 깨는 변경은 명시적인 버전 변경으로 관리한다.
- 생성 코드는 직접 수정하지 않는다.

코드 생성 명령과 생성물 위치는 도구 구성이 확정되면 기록한다.
