# Go 서비스

이벤트 티켓 예약 시스템의 애플리케이션 코드를 관리한다.

## 초기 서비스 구성안
- Catalog: 이벤트와 좌석 정보 조회
- Reservation: 좌석 임시 확보, 예약 확정·취소·만료
- Ticket: 예약 확정 이벤트 소비, 티켓 발급 및 조회

## 구현 원칙
- 즉시 응답이 필요한 서비스 간 통신은 gRPC를 사용한다.
- 비동기 후속 처리는 Kafka 이벤트로 연결한다.
- 재시도와 중복 이벤트를 안전하게 처리한다.
- DB 변경과 이벤트 발행은 outbox 방식으로 연결한다.
- 요청 취소, deadline, 정상 종료를 처리한다.
- 구조화 로그, 메트릭, 트레이스 계측을 포함한다.

서비스별 테스트와 DB migration은 해당 서비스와 함께 관리한다.
실제 서비스 경계는 구현 과정에서 검증하고 변경 이유를 문서화한다.
